# Kernel Kittens GitHub Pages Domain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the tested Kernel Kittens site from `SpookyMoo/KernelKittens` at `https://kernelkittens.team` with GitHub Pages.

**Architecture:** GitHub Actions builds and tests the Astro site, uploads the exact `dist` directory as a Pages artifact, and deploys it through the protected Pages environment. Porkbun remains authoritative and points the apex and `www` records at GitHub Pages.

**Tech Stack:** Astro 7, Vitest, Playwright, GitHub Actions, GitHub Pages, Porkbun DNS

## Global Constraints

- Keep Gitea as a separate backup remote.
- Never force-push shared history.
- Public release gates must pass before push.
- Do not expose credentials, private challenge data, or unpublished flags.
