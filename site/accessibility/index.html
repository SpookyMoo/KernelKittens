Accessibility

This site is built for keyboard, screen reader, zoom, reduced-motion, and high-contrast use.

Our target

We target WCAG 2.2 Level AA and test the public routes with automated browser and accessibility checks. The site uses semantic HTML, visible focus, system fonts, and no required client-side JavaScript outside the application.

Report a problem

If something blocks you, email accessibility@kitsunetechnologies.org. Include the page address and what you were trying to do if you can. We aim to acknowledge accessibility reports within 48 hours.

Known gaps

We do not currently know of a critical accessibility blocker. Automated checks cannot catch every problem, so direct reports still matter.
